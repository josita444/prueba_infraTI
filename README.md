# ⚡ FocusForge AI — Planificador Cognitivo de Estudio (`prueba_infraTI`)

**FocusForge AI** es una aplicación web desarrollada en **Python y Flask** que organiza dinámicamente tareas académicas y proyectos según el **nivel de energía mental** del usuario (`Alta`, `Media` o `Baja`), calculando bloques de concentración basados en la técnica **Pomodoro**.

---

## 🚀 ¿Qué hace y cómo funciona?

1. **Priorización Adaptativa por Energía:** 
   - Cuando seleccionas **Energía Alta**, el algoritmo posiciona primero las tareas de alta complejidad cognitiva para aprovechar tu máximo rendimiento.
   - Cuando seleccionas **Energía Baja**, reorganiza la ruta priorizando tareas ligeras o de repaso para evitar el agotamiento y mantener el impulso.
2. **Cálculo Automático de Métricas:** Muestra en tiempo real el total de misiones pendientes, los minutos acumulados y la cantidad de bloques Pomodoro (25 min) necesarios.
3. **Gestión Dinámica de Misiones:** Permite agregar nuevas tareas con su materia, dificultad y tiempo estimado, además de marcarlas como completadas con un clic.

---

## 🛠️ Tecnologías Utilizadas

- **Python 3** & **Flask** (Backend y lógica de priorización)
- **HTML5** & **Jinja2** (Renderizado dinámico de vistas)
- **CSS3** (Diseño responsivo estilo Cyber-UI con variables y Flexbox/Grid)
- **Git & GitHub** (Control de versiones con flujo de ramas `main` y `develop`)
